# 📝 To-Do List

A simple and responsive To-Do List web application built using HTML, CSS and JavaScript.

## 🚀 Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Task priority
- Due date
- Task statistics
- Dark mode
- Local storage
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
